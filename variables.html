Level 2: Variables

Variables:

Variables are used to make the computer remember information to display or change. It is like a storing game. You can organize your storage box by adding a label for where the T-shirt belongs to the ‘clothing’ box. In this case, the variable is clothing, and the content inside is value. And it look like this:

let clothing = “T-shirt”

To create a variable, we use let or const.

let ball;

We use the assignment operator = to put some data into the variable we just made.

ball = ‘basketball’;

(We use semicolons (;) to end a statement. Without it, the computer doesn't know when your statement ends and makes an error. Remember to add a semicolon when you end a statement!)

The string is now saved into the memory area associated with the variable. We can assess it by the variable name:

alert(ball);

Different ways to declare variables:

Const vs. let

There are multiple ways to declare variables. Other than the let we talked about, there is also const and var.

Const:

By using const, you can't change the value of a variable in the same way you can with let. You need to find the line where you declared the variable to change its value directly. If you do this:

const arrow = “Go to right”;
arrow = “Go to left”; //You will get an error.

You can think of let as a "snap-on battery box" because you can easily open the battery box and change the battery (the value of the variable). On the other hand, const is like a "screw-down battery box," which requires a tool (finding the line where the constant is declared and substituting the old value with the new value) to open and replace the battery inside. The process of finding the right tool refers to needing to find the line where the variable is declared, unlike let, where the value can be reassigned easily.
