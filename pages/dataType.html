Data Types

There are 8 types of data:

  • String
  • Number
  • Bigint
  • Boolean
  • Undefined
  • Null
  • Symbol
  • Object

Data is information stored in a computer. For example, it can store passwords, which are often stored as strings. Even if a password contains only numbers, it’s still treated as a string because the sequence of numbers matters, and it is not used for calculation.

let password = "12345";

console.log(password);

Console

12345

Data Types and Variable Assignments

Data types are dynamic because a variable's value can change between different data types.

  • Both var and let can be used to change a variable's value.
    • let rollingBoulder; // rollingBoulder is undefined
    • rollingBoulder = "active"; // now rollingBoulder is a string
    • rollingBoulder = 0; // now rollingBoulder is a number
  • But what about const?
    • It is true that the value assigned to a variable with const cannot be reassigned. But you can modify the contents of the object or array, such as changing the element inside it.
          • -->We will talk more about these later in the array lesson.

      const numbers = [6, 2, 7]; // You cannot reassign the entire array:

      numbers = [4, 5, 6]; // This will throw an error!

      // But you can modify the elements inside the array:

      numbers[0] = 9; // This is allowed

      numbers.push(4); // You can add new elements to the array

      console.log(numbers);

Console

[9, 2, 7, 4]

Strings

A string is a series of characters enclosed within single or double quotes.

Example:

  • "Touch the pressure plate!"
  • "1234567"
  • "Caution: Time limit is 1 minute."

If you need to use quotes inside a string, you can either:

  • Use single quotes inside double quotes
  • Use double quotes inside single quotes

let camouflageBlocks = "It’s'SAFE' to touch it";

let message = "riddle: 'What can you break without touching it?'";

let answer = "A: 'A promise'";

console.log(camouflageBlocks);

console.log(message);

console.log(answer);

Console

It’s'SAFE' to touch it

riddle: 'What can you break without touching it?'

A: 'A promise'

Numbers

Just numbers!

Example:

  • 8765678
  • 888.88

Numbers can also be written in scientific notation:

123e5 // 12300000 (e5 = move the decimal point 5 places to the right)

888e-3 // 0.888 (e-3 = move the decimal point 3 places to the left)

Console

12300000

0.888

Undefined

A variable with no value is undefined.

Example:

let invisibleWall; // undefined

You can also set the variable to undefined.

let invisibleWall = "inactive"; // invisibleWall is defined.

invisibleWall = undefined; // Now invisibleWall is set to undefined. It doesn’t hold any value.

console.log(invisibleWall);

Console

undefined

Null

null is a special value that represents the "no value" or "empty" state.

This is different from undefined because null is intentionally assigned to a variable to show that it has no value. undefined just means a variable has not been assigned a value yet.

let secretPassage = null; // secretPassage is intentionally set to have no value

console.log(secretPassage);

let trapDoor; // trapDoor is undefined because no value has been assigned

console.log(trapDoor);

Console

null

undefined

Object

An object is a collection of properties, written inside curly braces {}.

Object properties are written as name:value pairs, separated by commas.

const passcode = {
    "object orientation": "1,3,5,7,8",
    "active pressure plate": "red",
    gravity: 2 // The name needs to be inside " " or '' if it has a space or special character, but quotes are optional if it does not.
};

    // The object passcode contains 3 properties: (object orientation, active pressure plate, gravity)

console.log(passcode);
console.log(passcode["object orientation"]);

Console

{

"object orientation": "1,3,5,7,8",

"active pressure plate": "red",

gravity: 2

}

1,3,5,7,8

The typeof Operator

You can use the typeof operator to find the type of the value.

typeof "" // returns "string" because empty quotes represent a string.

typeof (3 + 4) // returns "number"

typeof true // returns "boolean"

typeof undefined // returns "undefined"

Sprites with an Image in p5play

Use sprite.image (or sprite.img) to add an image to the sprite!

  • To add an image, you need to provide the URL path to an image file.
  • When developing a game, you can create an assets folder to store all images (in PNG or other formats).
  • Then, use the path as a URL. For example: '/assets/openedDoor.png'
let door;

function setup() {
    new Canvas(300, 300);
    door = new Sprite(150, 150, 200, 150);
    door.img = '/assets/openedDoor.png';
}

Try it! Replace the image of door with closedDoor.png


JS often uses conditional statements to run a specific piece of code when a certain condition is met. If the condition isn't met, it runs something else. For example, when a button is pressed, a trap is activated, and an arrow shoots out. But when it remains unpressed, the trap is not activated.

sprite.image.offset:

Use sprite.image.offset to adjust the image’s position relative to the center of the sprite.

You can make the image higher, lower, or more to the right or left.

It's especially useful when making a sprite collidable with other sprites.

function setup() {
    new Canvas(300, 300);
    door = new Sprite(150, 150, 200, 150);
    door.img = '/assets/openedDoor.png';
    door.img.offset.y = 10;
    door.img.offset.x = -10;
}

sprite.debug:

Set sprite.debug = true to see the sprite's physics body collider.

This is helpful, especially when you want to use sprite.image.offset because you can see the shape and center of the sprite.

function update(){
    clear();
    door.debug = true;
    // The debug is in the update because the collider needs to continue to show even when the sprite moves.
}

The debug for the sprite on the canvas is false. Turn it on!


door.debug = true;
