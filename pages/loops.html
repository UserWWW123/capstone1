Loops

By using loops, the computer can runs a block of code multiple times.


Different kinds of loops:

->for loop

A block of code runs until a specific condition becomes false.

->while loop

Loop through a block of code while a condition is true.

For Statement:

Syntax:

for (expression 1; expression 2; expression 3) {
            // code to run
        }

Expression 1: Initialization

Define a variable and set it to 0. The variable can also be another number, but it's commonly set as 0.

i is commonly used as a loop variable.

let i = 0;

Expression 1 is optional because you can define the variable and set it to a numeric value before the loop starts.

You can also define multiple variables, separated by commas.


Expression 2: Condition

Provide a condition that determines how long the loop should run. The loop continues while the condition is true.

Important: Make sure your condition allows the loop to eventually stop. For example:

i < 3;

If you write a condition like i > 3, and i starts at 0, the loop will never run. If the condition never becomes false, the loop can run forever and crash your browser.


Expression 3: Final Expression

This code runs after each loop iteration. It's commonly used to update the loop counter, for example:

i++;

This increases i by 1 after each loop.

You can also decrement or use more complex expressions depending on your logic.

Difference Between var and let in a Loop

What happens when you declare i both inside and outside a loop with a different value?


var

The value declared inside the loop affects the value outside the loop.

var i = 2;
        for (var i = 0; i < 20; i++) {
            // code
        }
        // i is now 20

let

The value declared inside the loop is only for the loop. The value will not appear outside of the loop.

let i = 2;
        for (let i = 0; i < 20; i++) {
            // code
        }
        // i is still 2

Note:

This behavior is similar to how const behaves inside a function or block.

while Loop

The while loop runs code as long as a specific condition is true. 

let i = 5;
    while (i > 0) {
        console.log('The no-fire countdown for the firewall lasts only ' + i + ' seconds.');
        i--;
    }

Difference between while Loop and for Loop

  • You can use a while loop when you don't know how many times you want the code to loop.

  • You can use a for loop when you know how many times you want the code to loop, such as when you know the exact number of iterations.

Group:

Use a group to make an array and store sprites inside the array! You can edit the sprites in the group at once — much convenience!

Use sprites.length to get the number of sprites in the group. You can also adjust a sprite in the group using its index. 

let sprites;
      function setup(){
        sprites = new Group();
        sprites.w = 10;
        sprites.h = 10;
        sprites.y = 20;
      
        while (sprites.length < 10) {
          let sprite = new Sprite();
          sprite.x = sprites.length * 20; // 20px gap between sprites
        }
      
        sprites[2].y = 100;
      }

Steps:

  • Create a new group called balls.
  • Set the collider type of the group to 'dynamic' so that the sprites are affected by physics.
  • Set the color of the balls in the group to '#C8553D'.
  • Set the stroke (outline) color for the group to '#F28F3B'.
  • Set the diameter of the sprites in the group to 30 pixels.
  • Create 10 sprites using a for loop. Use i as the loop variable.
  • Set the gap between the sprites to 200 pixels, and position them starting 1800 pixels above the canvas.

    • Note

    After using the closing curly brace }, you don't need to use a semicolon because the curly brace marks the end of the code block. But you can if you want. It doesn't cause any error.

Remove Sprites:

You can use the remove() function to remove individual sprites.

Example: sprite[5].remove();

You can use the removeAll() function to remove multiple sprites from a group.

Example: sprites.removeAll();

allSprites:

You can also use allSprites to control all sprites on the canvas at once!

Example: allSprites.removeAll();
