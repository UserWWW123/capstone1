Variables:

Variables are used to make the computer remember information to display or change. It is like a storing game. You can organize your storage box by adding a label for where the T-shirt belongs to the ‘clothing’ box. In this case, the variable is clothing, and the content inside is value. And it look like this:

let clothing = “T-shirt”

To create a variable, we use let or const.

let ball;

We use the assignment operator = to put some data into the variable we just made.

ball = ‘basketball’;

Important:

We use semicolons (;) to end a statement. Without it, the computer doesn't know when your statement ends and makes an error. Remember to add a semicolon when you end a statement!

The string is now saved into the memory area associated with the variable. We can assess it by the variable name:

console.log(ball);

We can also declare multiple variables in one line:

let ball = 'basketball'; amount = 25; color = 'orange';

But it is better to use the multiline variant:

let ball = 'basketball';

let amount = 25;

let color = 'orange';

It may look cumbersome, but you will thank yourself later. Because it is much easier to read when you have a lot of variables!

Never claim a variable twice:

A variable can only be declared once. Make sure to make the variable name one you can remember and unique. But you can change the value inside the variable anytime by doing this:

let ball = 'basketball'; // declare ball

ball = 'softball'; // value changed

Important:

We use // in JS to make comments. It’s important to make comments to make the code easy to understand for yourself or others for later analysis and debugging purposes.

In the example above, the variable ball is declared once, and its value is changed later from 'basketball' to 'softball'. You can change the value of a variable as many times as you need, but the declaration can only happen once.

We can also declare two variables and copy data from one into another:

let StoneCount = 2; // declare StoneCount

let stoneAdded = 4; // declare stoneAdded

StoneCount = StoneCount + stoneAdded; // now StoneCount holds the sum of StoneCount and stoneAdded

Different ways to declare variables:

Const vs. let vs. var:

There are multiple ways to declare variables. Other than the let we talked about, there is also const and var.

Var:

Var is very similar to let. You can change the value. Var is the older version of let. They have a very similar function.

Const:

By using const, you can't change the value of a variable in the same way you can with let. You need to find the line where you declared the variable to change its value directly. If you do this:

const arrow = “Go to right”;

arrow = “Go to left”; //You will get an error.

Console

error

You can think of let as a "snap-on battery box" because you can easily open the battery box and change the battery (the value of the variable).

On the other hand, const is like a "screw-down battery box," which requires a tool (finding the line where the constant is declared and substituting the old value with the new value) to open and replace the battery inside.

The process of finding the right tool refers to needing to find the line where the variable is declared, unlike let, where the value can be reassigned easily.

Variable Naming:

There are two limitations on variable names in JavaScript:

  • The name must contain only letters, digits, or the symbols $ and _.
  • The first character must not be a digit.

Examples of valid names:

  • let day1;

  • let_;

Examples of invalid names:

  • let zoneGravity;

  • let 5C;

Every variable needs a name. Variable names need to be on a single line and without space in between. When there are multiple words in one variable, we make the first letter of each word capitalized, like this: lessGravityArea.

Tips:

  • The dollar sign $ and the underscore _ can also be used in names.
  • AAA and aaa are different variables → lowercase or uppercase matters!
  • There is a list of reserved words that you cannot use as variable names because they are used by the language itself.

For example:

  • let
  • const
  • class
  • function
  • return
