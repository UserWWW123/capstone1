Function:

A JavaScript function is a block of code that can be used repeatedly. It is defined by the function keyword and a user-assigned name. A function is different from writing code line by line not only because it is reusable but also because it doesn't run until you call it.


Different kinds of loops:

->for loop

A block of code runs until a specific condition becomes false.

->while loop

Loop through a block of code while a condition is true.

Step 1. Write a function.

Here is how to write a function:

Syntax:

function name(parameter1, parameter2, parameter3) {
  //Code
};

Function names follow the same rule as variables. (e.g. they can contain letters, digits, and underscores)

Parameters are placeholders for values that the function can receive later. When the function is called, the values passed into the function are called arguments. Inside the function, the arguments behave as local variables, which means they exist only inside the function.

You can assign a name to a parameter. For example: 'area1':

function arrowNumberCalculation(area1, area2) {
  return area1 + area2;
};

Step2. Call the function:

There are different ways to call a function. You can:

  • Directly call it in the code
  • Use an event (e.g., click a button)
  • Invoke it automatically when the page loads

1) Directly call it in the code:

You can call a function at a specific point in your program. For example, as a condition is fulfilled (x + y === 2), the function is called. This method is usually used when the function has a parameter to pass a specific value in it.

let result = arrowNumberCalculation(12, 26);

You can also call a function based on user input. For example, when the user submits the block’s position value, the block's position on the canvas is updated. In this case, you can use DOM.

Important:

DOM (Document Object Model):

When a web page is loaded, the browser creates a DOM of the page. Using the HTML DOM, JavaScript can access and modify all the elements of an HTML document, including HTML structure and CSS styles.

For example, with the DOM, you can:

  • Find an input box and the submit button in the HTML by their Ids.
  • Detect if the submit button is clicked. If clicked, get the values from the input box.
  • Remove the existing block (if any) before creating a new block.
  • Create a block with the position that the user submitted.

Default parameter in JS:

If a function with a parameter is called without arguments (no value added), the missing values are set to undefined.

Sometimes this is okay, but it is better to assign a default value to the parameter to prevent errors.

JS will use these default values when the function is called without arguments. This prevents undefined situations and ensures the function still works.

Syntax:

With default parameters:

function callCharacter(name = 'friend') {
    console.log('Hello,' + name);
}
callCharacter(); // Hello, friend
callCharacter('Leo'); // Hello, Leo

Without default parameters:

function callCharacter(name) {
    console.log('Hello,' + name);
}
callCharacter(); // Hello, undefined
callCharacter('Leo'); // Hello, Leo

A function doesn't always need a parameter.

If you don't need to input anything but just want the function to act like a code block that can be reused in different places repeatedly, it works!

Return:

When JS reaches a return statement, it will stop executing. If the function is invoked with arguments, JavaScript will 'return' the result of the code inside the function. Any code after 'return' will be ignored. Functions are often designed to compute a value. The argument will pass to the function. The result will then 'return' back to where the function was invoked.

Example with return:


function ballWeight(amount) {
return 10 * amount; // one ball weighs 10. 10 * amount = total weight.
console.log('Code after return'); // This will not run.
}

console.log(ballWeight(2)); // Result of the calculation returns to its argument.
// Code after return will not run because it is after a return statement.

Accessing a Function Without ()

When you access a function without using parentheses (), you get the function itself and not the result of the function. This is because JavaScript treats the function reference as an object and not as an invocation.

Example:


function convertToCelsius(fahrenheit) {
    return (5/9) * (fahrenheit - 32);
};
convertToCelsius;
console.log(convertToCelsius()); 
console.log(convertToCelsius(50));

Console

Process:

  1. The function convertToCelsius(50) is called, passing 50 as an argument.
  2. Inside the function, the calculation is performed, and the value 10 is returned.
  3. The value 10 is returned to the place where the function was called, which is console.log(convertToCelsius(50)).
  4. The result prints to the console.

Use loadAnimation() (or loadAni()) to load animations!

There are different ways to add images to an animation:

  • You can use separate image files.
  • Or you can use a sprite sheet.

If the animation only includes a few images, you can use list mode:


    // Load animation with separate image files
    alienAni = loadAnimation(
        'assets/walk1.png',
        'assets/walk2.png'
    );

What is a Sprite Sheet?

A sprite sheet is a single image file that contains many smaller images that are arranged in grids. In animation, these smaller images are images for each frame.

Here is an example of a sprite sheet:

How to Use Them:

Sequence Mode:

Upload a sprite sheet and specify how many frames you want to play. p5play will play the images horizontally from the start. (As shown on the canvas to the left)

alien = loadAnimation('/assets/spritesheet_aliens.png', {width: 128, height: 256, frames: 8}); //width and height of each frame + frames amount

Frames will play in the order: 1, 2, 3...

You can also specify which frames you want to play. (As shown on the canvas to the right)

alien = loadAnimation('/assets/spritesheet_aliens.png', {width: 128, height: 256, frames: [1, 8, 16, 24, 32, 40, 48, 56]}); // List the frames you want to play. Counting starts at 0 and goes from left to right, top to bottom.

frameDelay:

Use frameDelay to control the speed of changing frames for animation!

Format:


    let alien;
    function setup(){
        new Canvas(300,300);
        alien = loadAnimation('/assets/spritesheet_aliens.png', {width: 128, height: 256, frames: 8});
        alien.scale = 2;
        alien.frameDelay = 10; // Play the animation at a slower speed
    }
    function update(){
        background('#8D9F87');
        animation(alien, 300/2, 300/2); // Place the animation on the canvas and set the position
    }

List Mode:

In list mode, upload separate image files. p5play will play the images in the order you list them. (frameDelay = 30)

Add Animation to a Sprite:

addAni

Use addAni() with the name of the animation (like 'walk' or 'jump'), along with the frame files and number of frames, using one of the methods described above:


    alien.addAni('walk', ['/assets/alienYellow_walk1.png', '/assets/alienYellow_walk2.png'], 2);
    alien.addAni('stand', ['/assets/alienYellow_front.png'], 1);

You can use the keyboard (kb) to control which animation plays!

To flip the sprite image horizontally (e.g., to face left), use sprite.scale.x = -1.


if (kb.pressing('left')) {
    alien.changeAni('walk');
    alien.vel.x = -5;
    alien.scale.x = -2;
} else if (kb.pressing('right')) {
    alien.changeAni('walk');
    alien.vel.x = 5;
    alien.scale.x = 2;
} else {
    alien.changeAni('stand');
    alien.vel.x = 0;
}
