Conditional Statements: if/else/else if

JS often uses conditional statements to execute a specific piece of code when a certain condition is met. If the condition isn't met, it performs something else. For example, when a button is pressed, a trap is activated and an arrow shoots out. But when it remains unpressed, the trap is not activated.

In code, this situation looks like:

if (buttonPressed) {

    // an arrow shoots out

} else {

    // the trap remains inactive

}

Common conditional statements in JS:

  • if: If its condition is true, its code will be executed.
  • else if: If the previous condition is false and the current condition is true, the code inside will be executed.
  • else: If previous if and else if conditions are false, the code inside will be executed.

Conditional Statement Structure

The order is like this:

if (condition1) {

  // code will be executed if condition1 is true

} else if (condition2) {

  // code will be executed if condition1 is false and condition2 is true

} else {

  // code will be executed if condition1 and condition2 are both false

}

There can only be one if statement and one else statement in a single conditional block.

There can be multiple else if statements in the same block to check additional conditions.

p5play time! Let's learn more about p5play!

With p5play, you can easily detect mouse movement and change sprite movement based on it.

sprite.mouse

sprite.mouse: Use it to detect mouse interaction related to the sprite.

sprite.mouse.dragging: Make the sprite draggable by clicking and moving it with the mouse.

sprite.mouse.hovering: Detect when the mouse is hovering over a sprite.

sprite.mouse.x: Detect the mouse's x position relative to the sprite.

sprite.mouse.y: Detect the mouse's y position relative to the sprite.

function draw() {
  background(57, 92, 107);
  world.gravity.y = 10;

  mouseXSprite.text = mouse.x;
  mouseYSprite.text = mouse.y;

    alien.moveTowards(mouse.x + alien.mouse.x, mouse.y + alien.mouse.y, 1);

    alien.img = alien2img;
  } else {
    alien.img = alien1img;
  }

  if (mouse.x >= 500) {
    alien.collider = 'dynamic';
  }
}

mouse

mouse: Used to detect mouse movement.

mouse.pressing: Detect when the mouse is being pressed.

mouse.x: Detect the mouse's x position on the page.

mouse.y: Detect the mouse's y position on the page.

mouse.visible: Set whether the mouse is visible. true = visible, false = invisible.

mouse.cursor: Set how the mouse cursor appears.

Cursor types: default, grab, move, pointer, wait (hover over the words to see how they look!)

      alien.vel.y = -4;
    }

      if (crate.mouse.pressing()) {

          p.mouseY + crate.mouse.y,

      }

      if (crate.mouse.released()) {

      }

    }

    if (crates.mouse.hovering() || alien.mouse.hovering()) {
      p.mouse.cursor = 'grab';
    } else {
      p.mouse.cursor = 'wait';
    }
  };

Keyboard (kb)

Keyboard track keys on the keyboard, from normal letter and number to 'enter', 'backspace', 'control', and 'shift'.

kb.pressing('shift');

Track user movement:

There are usually two ways to track user movement using keys. Use arrows and WASD:

  • Arrow: 'arrowUp', 'arrowDown', 'arrowLeft', 'arrowRight'.
  • WASD: 'up', 'down', 'left', 'right'.

If you want a second user, like a battle game, you can use IJKL:

  • 'up2', 'down2', 'left2', 'right2'.
kb.pressing('arrowUp');

Camera Movement:

You can change the visible area (camera) by using camera.x and camera.y. Just like moving a camera in real life, if you increase the value of camera.x, the visible area of the canvas moves to the right. By default, the camera is located at the center of the canvas. You can use a camera.moveTo(x,y) to move the camera!

If you want the camera to move as the sprite moves, use the drawFrame() function, because drawFrame() runs after the physics simulation is updated. Try moving the camera by moving the sprite with the arrow keys!

camera.on() & camera.off():

Want to make an element fixed in a place while the camera moves? Here you go! Use camera.off() for elements you don't want to move—it makes them stick to the screen (like a label). For example, you can make a score sprite fixed at the top-left corner.

Use camera.on() for elements you want to be affected by the camera movement. Call sprite.draw() after camera.off() to draw elements that should be fixed and not move with the camera. Call sprite.draw() after camera.on() to draw elements that should move with the camera. 


const s4 = (p) => { 
    let alien, alienimg, hitT;
    let blocks, startButton, backgroundimg;
    let gameStarted = false; // To track whether the game has started
    let hit = 0; // To track the hit
    let isPaused = false;
    
    p.preload = () => {
        alienimg = p.loadImage('/assets/shipYellow.png');
        backgroundimg = p.loadImage('/assets/uncolored_piramids.png');
    };
    
    p.setup = () => {
        p.createCanvas(1200, 500);
        p.world.gravity.y = 10;
    
        alien = new p.Sprite(-300, 100, 60, 20, 'none'); 
        alien.addCollider(0,-20, 33); //(x-offset, y-offset, diameter)
        alien.addCollider(0,10,60,15);
        alien.addCollider(-23,20,20);//13 left from the center. 20 down from the center. 20 diameter
        alien.addCollider(23,20,20);
        alien.offset.y = -10;
        alien.img = alienimg;
        alien.scale = 1.5;
        alien.debug = true;
        alien.collider = 'dynamic';
        alien.rotationLock = true;
        alien.vel.x = 0;
        alien.friction = 0;
        alien.bounciness = 0;

        hitT = new p.Sprite(70,30,100,30, 'none');
        hitT.color = 'white';
        hitT.stroke = 'white';
        hitT.text = hit;
        
        blocks = new p.Group();
        
        for (let i = 0; i < 100; i++) {
            let gapSize = p.random(60,100); // Make gaps' height bigger/smaller
            let gapY = p.random(150,300); // Gaps location

            let topBlock = new p.Sprite(i*250+200, gapY - gapSize - 250, 100, 500, 'static');
            topBlock.color = '#FAF3DD';
            topBlock.stroke = '#FFA69E';
        
            let bottomBlock = new p.Sprite(i*250+200, gapY + gapSize + 250, 100, 500, 'static');
            bottomBlock.color = '#FAF3DD';
            bottomBlock.stroke = '#FFA69E';
            
            blocks.add(topBlock);   // Add the blocks to the group
            blocks.add(bottomBlock);
        };

        blocks.bounciness = 0;
        startButton = new p.Sprite(alien.x, 250, 200, 100, 'static');
        startButton.color = 'white';
        startButton.stroke = 'white';
        startButton.opacity = 0.5;
        startButton.text = 'Click to start';
        startButton.textSize = 20;
    };
    
    p.draw = () => {
        p.background(backgroundimg);
        if (startButton.mouse.presses()) {
            startButton.remove();
            gameStarted = true; // Game has started
        };

        if (gameStarted && !isPaused) {
            alien.vel.x = 3; // Set vel.x to 3 only after the game has started and game is not paused by using space
        };

        if (p.mouse.presses()) {
            alien.vel.y = -3;  
        };

        if (p.kb.presses('space')) {
            if (!isPaused) { //When it's not paused, pause the game
                alien.vel.x = 0;
                alien.vel.y = 0;
                alien.collider = 'static';
                isPaused = true;
            } else { //When it's paused, unpause the game.
                alien.collider = 'dynamic';
                alien.vel.x = 3;
                isPaused = false;
            };
        };


        blocks.forEach(block => { // Check collisions with each block individually
            if (alien.collide(block)) {
                hit += 1;  // Increment hit for each collision with a block
            };
        });
        if (hit >=10){
            alien.x = -300;
            hit = 0;
        };

        if (alien.y>600){
            alien.y = 100;
            alien.x = -300;
            hit = 0;
            alien.vel.y = 0;
        };
    };
    
    p.drawFrame = () => {
        p.camera.on();
        p.camera.x = alien.x;  
        alien.draw();
        blocks.draw();

        p.camera.off();
        hitT.text = `Hits: ${hit}`; // Update hit display
        hitT.draw();        
    };
};

new p5(s4, 'camera');
