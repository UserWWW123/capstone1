    You are on a spy mission. After two months of undercover work, you finally obtain the password to open the door in the enemy base where your friend is being held. But you're marked. You need to pass the password to another colleague. Now is the time!

    Instruction:

    1. Create a variable called password.

    2. Create a sprite called whisper.

    3. Set the sprite’s width, then height, followed by x, and y.

    4. Assign a value "87537979" to the password variable.

    5. Set the sprite’s text size to be 20.

    6. Set the sprite’s text to be the value of the password variable.
