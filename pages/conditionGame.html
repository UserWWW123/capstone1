    If-Else

    An alien is trapped in a room!

    The room is designed so that the door will not open until the monster is defeated.

    Create and play a game following the instructions below.

    How to play?

    Control the alien to collect a block and use it to hit the monster to unlock the door!

    ⚠️ Watch out for the monster’s attacks!⚠️
    If the alien's life reaches 0, the game will restart.

    How to collect a block?

    • Jump on top of the block and press down to pick it up.
    • Press space to throw the block and hit the monster!

    Instruction:

    1. Create a setup function
      1. Create a canvas using the container’s width and height
      2. Set the background color as #dbb691ff
      3. Set world.gravity.y = 15
    2. Create alien sprite, set its properties in the following sequence:
      1. layer = 2
      2. rotationLock = true
    3. Create blockA sprite, set properties in this sequence:
      1. layer = 1
      2. img
      3. img.scale = 0.4
      4. img.offset.y = -20
      5. collider = 'dynamic'
    4. Create alienLifeS sprite, set its properties in the following sequence:
      1. Position and size: (100, 30, 170, 30)
      2. textSize = 20
      3. collider = 'none'
      4. color = '#F5EE9E'
      5. stroke = 'white'
      6. textColor = '#AB3428'
      7. strokeWeight = 2
      8. opacity = 0.7
    5. Create a draw function
      1. Clear background with color #dbb691ff
    6. Create a drawFrame function
      1. Turn on camera
      2. Set the camera to follow the alien horizontally, keeping it slightly ahead by 200 pixels
      3. Turn off camera
      4. Draw alienLifeS
    7. Create an update function
      1. Make alienLifeS show text with Alien Life and the current life count of the alien
      2. Use conditional statement and keys input to create the following functions:
        1. If up key is pressed:
          • Alien jump
        2. If right key is being pressed:
          • Alien move to the right
        3. Else if left key is being pressed:
          • Alien move to the left
        4. If down key is being pressed and alien.collides(blockA) is true:
          • Set alien.vel.x = 0
          • Set collectBlock = true
        5. Else if space key is pressed and collectBlock is true:
          • Set blocks.collider = 'dynamic'
          • Launch blockA with:
            • blocks.vel.x = 5
            • blocks.vel.y = -5
          • blockA.rotationLock = false
          • Set collectBlock = false
        6. If collectBlock is true:
          • Set blocks.collider = 'none'
          • Update blockA to follow the alien:
            • blockA.x = alien.x + 50
            • blockA.y = alien.y + 10
            • blockA.rotationLock = true
            • blockA.rotation = 0
    
function setup(){
    createCanvas(865, 750);
    background('#dbb691ff');

    world.gravity.y = 15;

    alien = new Sprite(90, 150, 0, 0, 'dynamic');
    alien.layer = 2;
    alien.rotationLock = true;

    blockA = new Sprite(200, 80, 50, 45);
    blockA.layer = 1;
    blockA.img = 'assets/block.png';
    blockA.img.scale = 0.4;
    blockA.img.offset.y = -20;
    blockA.collider = 'dynamic';

    alienLifeS = new Sprite(100, 30, 170, 30);
    alienLifeS.textSize = 20;
    alienLifeS.collider = 'none';
    alienLifeS.color = '#F5EE9E';
    alienLifeS.stroke = 'white';
    alienLifeS.textColor = '#AB3428';
    alienLifeS.strokeWeight = 2;
    alienLifeS.opacity = 0.7;
};

function draw(){
    background('#dbb691ff');
};

function drawFrame(){
    camera.on();
    camera.x = alien.x + 200;

    camera.off();
    alienLifeS.draw();
};

function update(){
    alienLifeS.text = 'Alien Life: ' + alienLife;

    if (kb.presses('up')){
        alien.vel.y = -5;
    }

    if(kb.pressing('right')){
        alien.vel.x = 2.5;
    } else if(kb.pressing('left')){
        alien.vel.x = -2.5;
    }

    if (kb.pressing('down') && alien.collides(blockA)) {
        alien.vel.x = 0;
        collectBlock = true;
    } else if (kb.presses('space')) {
        if (collectBlock === true){
            blocks.collider = 'dynamic';
            blocks.vel.x = 5;
            blocks.vel.y = -5;
            blockA.rotationLock = false;
            collectBlock = false;
        };
    };

    if (collectBlock === true) {
        blocks.collider = 'none';
        blockA.x = alien.x + 50;
        blockA.y = alien.y + 10;
        blockA.rotationLock = true;
        blockA.rotation = 0;
    };
};
