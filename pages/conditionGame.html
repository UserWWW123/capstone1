    If-Else

    An alien is trapped in a room!

    The room is designed so that the door will not open until the monster is defeated.

    Code a section of the game and play the game following the instructions below.

    How to play?

    Control the alien to collect a block and use it to hit the monster to unlock the door!

    ⚠️ Watch out for the monster’s attacks!⚠️
    If the alien's life reaches 0, the game will restart.

    How to collect a block?

    • Jump on top of the block and press down to pick it up.
    • Press space to throw the block and hit the monster!

    Instruction:

    1. Declare variables in the following sequence:
      • alien, monster, door, blockA, alienLifeS, monsterLifeS
      • movingRight(set to true)
      • alienLife (set to 10)
      • monsterLife (set to 10)
      • collectBlock (set to false)
    2. Create a setup function:
      1. Create a canvas with width of 865 and height of 750
      2. Set the background color as #dbb691ff
      3. Set world.gravity.y = 15
    3. Create door sprite, set its properties in the following sequence:
      1. door.img = '/assets/closedDoor.png';
    4. Create alien sprite, set its properties in the following sequence:
      1. image
      2. layer = 2
      3. rotationLock = true
    5. Create monster sprite, set its properties in the following sequence:
      1. image
      2. layer = 2
      3. rotationLock = true
    6. Create blockA sprite, set properties in this sequence:
      1. layer = 1
      2. img
      3. img.scale = 0.4
      4. img.offset.y = -20
      5. collider = 'dynamic'
    7. Create alienLifeS sprite, set its properties in the following sequence:
      1. Position and size: (100, 30, 170, 30)
      2. textSize = 20
      3. collider = 'none'
      4. color = '#F5EE9E'
      5. stroke = 'white'
      6. textColor = '#AB3428'
      7. strokeWeight = 2
      8. opacity = 0.7
    8. Create monsterLifeS sprite, set its properties in the following sequence:
      1. Position and size: (100, 70, 170, 30)
      2. textSize = 20
      3. collider = 'none'
      4. color = '#F5EE9E'
      5. stroke = 'white'
      6. textColor = '#AB3428'
      7. strokeWeight = 2
      8. opacity = 0.7
    9. Create a draw function:
      1. Clear background with color #dbb691ff
    10. Create a drawFrame function:
      1. Turn on camera
      2. Set the camera to follow the alien horizontally, keeping it slightly ahead by 200 pixels
      3. Turn off camera
      4. Draw alienLifeS
      5. Draw monsterLifeS
    11. Create an update function:
      1. Make alienLifeS show text with Alien Life and the current life count of the alien
      2. Make monsterLifeS show text with Monster Life and the current life count of the monster
      3. Use conditional statement and keys input to create the following functions:
        1. If up key is pressed:
          • Alien jump
        2. If right key is being pressed:
          • Alien move to the right
        3. Else if left key is being pressed:
          • Alien move to the left
        4. If down key is being pressed and alien.collides(blockA) is true:
          • Set alien.vel.x = 0
          • Set collectBlock = true
        5. Else if space key is pressed and collectBlock is true:
          • Set blockA.collider = 'dynamic'
          • Launch blockA with:
            • blockA.vel.x = 5
            • blockA.vel.y = -5
          • blockA.rotationLock = false
          • Set collectBlock = false
      4. If collectBlock is true:
        • Set blockA.collider = 'none'
        • Update blockA to follow the alien:
          • blockA.x = alien.x + 50
          • blockA.y = alien.y + 10
          • blockA.rotationLock = true
          • blockA.rotation = 0
      5. Monster's movement:
        • Use movingRight to track the direction of movement.
        • If movingRight is true:
          • Set monster's velocity to move right (monster.vel.x = 2).
          • If the monster reaches the right boundary (monster.x >= 800), monster's velocity = 0, change movingRight to false.
        • If movingRight is false:
          • Set monster's velocity to move left (monster.vel.x = -2).
          • If the monster reaches the left boundary (monster.x <= -50), monster's velocity = 0, change movingRight to true.
      6. Attacks or being attacked:
        • If the alien collides with the monster:
          • Decrease the alienLife by 1 (alienLife -= 1).
        • If the monster collides with the blockA:
          • Decrease the monsterLife by 1 (monsterLife -= 1).
      7. Make the door image change when the alien collides with it and defeated monster — the door opens!
    
  let alien, monster, door, blockA, alienLifeS, monsterLifeS;
  let movingRight = true;
  let alienLife = 10;
  let monsterLife = 10;
  let collectBlock = false;
  
  function setup(){
      new Canvas(865, 750);  // Correct canvas creation method
      background('#dbb691ff');
      world.gravity.y = 15;  // Ensure world.gravity exists in your environment
  
      // Door sprite
      door = new Sprite(1035,545,1,100, 'static');
      door.img = '/assets/closedDoor.png';
  
      // Alien sprite
      alien = new Sprite(90, 150, 0, 0, 'dynamic');
      alien.img = '/assets/alien.png';
      alien.layer = 2;
      alien.rotationLock = true;
  
      // Monster sprite
      monster = new Sprite(-50, 550, 30, 50, 'dynamic');
      monster.img = '/assets/monster.png';
      monster.layer = 2;
      monster.rotationLock = true;
  
      // Block sprite
      blockA = new Sprite(200, 80, 50, 45);
      blockA.layer = 1;
      blockA.img = 'assets/block.png';
      blockA.img.scale = 0.4;
      blockA.img.offset.y = -20;
      blockA.collider = 'dynamic';
  
      // Alien Life Sprite
      alienLifeS = new Sprite(100, 30, 170, 30);
      alienLifeS.textSize = 20;
      alienLifeS.collider = 'none';
      alienLifeS.color = '#F5EE9E';
      alienLifeS.stroke = 'white';
      alienLifeS.textColor = '#AB3428';
      alienLifeS.strokeWeight = 2;
      alienLifeS.opacity = 0.7;
  
      // Monster Life Sprite
      monsterLifeS = new Sprite(100, 70, 170, 30);
      monsterLifeS.textSize = 20;
      monsterLifeS.collider = 'none';
      monsterLifeS.color = '#F5EE9E';
      monsterLifeS.stroke = 'white';
      monsterLifeS.textColor = '#AB3428';
      monsterLifeS.strokeWeight = 2;
      monsterLifeS.opacity = 0.7;
  }
  
  function draw(){
      background('#dbb691ff');
  }
  
  function drawFrame(){
      camera.on();
      camera.x = alien.x + 200; // Camera follows the alien
  
      camera.off();
      alienLifeS.draw();
      monsterLifeS.draw();
  }
  
  function update(){
      // Update alien and monster life display
      alienLifeS.text = 'Alien Life: ' + alienLife;
      monsterLifeS.text = 'Monster Life: ' + monsterLife;
  
      // Player movement control
      if (kb.presses('up')){
          alien.vel.y = -5;
      }
  
      if(kb.pressing('right')){
          alien.vel.x = 2.5;
      } else if(kb.pressing('left')){
          alien.vel.x = -2.5;
      }
  
      // Collect or release block
      if (kb.pressing('down') && alien.collides(blockA)) {
          alien.vel.x = 0;
          collectBlock = true;
      } else if (kb.presses('space')) {
          if (collectBlock === true){
              blockA.collider = 'dynamic';
              blockA.vel.x = 5;
              blockA.vel.y = -5;
              blockA.rotationLock = false;
              collectBlock = false;
          }
      }
  
      // Collect block
      if (collectBlock === true) {
          blockA.collider = 'none';
          blockA.x = alien.x + 50;
          blockA.y = alien.y + 10;
          blockA.rotationLock = true;
          blockA.rotation = 0;
      }
  
      // Monster's movement
      if (movingRight === true) {
          monster.vel.x = 2;
          if (monster.x >= 800) {
              monster.vel.x = 0; // Stop the monster when reaching right boundary
              movingRight = false;
          }
      } else {
          monster.vel.x = -2;
          if (monster.x <= -50) {
              monster.vel.x = 0; // Stop the monster when reaching left boundary
              movingRight = true;
          }
      }
  
      // Attacks or being attacked
      if (alien.collide(monster)) {
          alienLife -= 1;
      }
  
      if (monster.collide(blockA)) {
          monsterLife -= 1;
      }
  
      // Win condition: door opens when monster is defeated and alien reaches door
      if (alien.collides(door) && monsterLife <= 0){
          door.img = '/assets/openedDoor.png';  // Door opens
      }
  }
