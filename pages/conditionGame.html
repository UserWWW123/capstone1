    If-Else

    An alien is trapped! Create a game following the instructions, and play the game to make the obstacle trapping the alien go away!

    Instruction:

    1. Create a sprite called ground.

    2. Create a sprite called user that follows the mouse.

    3. Make the user sprite able to click to create a sprite called new Sprite().

    4. Add images to the sprites in this sequence: doorClosed, doorway, arrow.

    5. Create an if statement to let door images change from doorClosed to doorOpen if new Sprite() hits it.

    6. Create an if statement to make a sprite speed up in a 40-degree direction when it contacts the arrow.

    7. Make the camera move as the new Sprite() moves.

    8. Make the ground not be impacted by the camera movement.

    9. Click to create new Sprite()! Make new Sprite() hit the door to open it!
