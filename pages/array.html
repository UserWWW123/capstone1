Arrays

An array is a special type of object.

Arrays are written inside square brackets [ ].

You can store items in a single variable through an array.

Array items are separated by commas.

const direction = ["west", "south", "north", "east"];

console.log(direction);

console.log(direction[2]);

Console

["west", "south", "north", "east"]

north

Syntax:

const arrayName = [item1, item2, …];

If you like, you can also write the array in this format:

const direction = [

"west",

"south",

"north",

"east"

];

// Both formats work the same way! Choose the style that fits you best!

You can also create an empty array and add values to it afterward:

const direction = [];

direction[0] = "west";

direction[1] = "south";

direction[2] = "north";

direction[3] = "east";

Index in Arrays

The index determines the position of a value in the array! You can access a value inside an array by referring to its index number. Just like how you access a page through its page number!

*Index starts from 0!

For example:

direction[0] refers to the first item in the array.

direction[3] refers to the fourth item in the array.

Why Are Arrays Special Kinds of Objects?

Arrays are special kinds of objects because they both store multiple values. Just like objects that use names to access their following elements, arrays use numbers to access the specific value.

Object Example:

const traps = {trapName: "Spikes", trigger: "step", amount: 10};

console.log(traps['trapName']);

Console

"Spikes"

Array Example:

const traps = ["Spikes", "Lever", "Hole"];

console.log(traps[1]);

Console

"Lever"

Array Properties and Methods

A method is a function that is associated with an object or data type. Since an array is an object, you can call methods that are provided by JavaScript to manipulate the array values.

It means you can use methods like push(), pop(), unshift(), shift(), sort(), length, and more!


push()

push(): Adds an item to the end of the array.

pop()

pop(): Removes an item from the end of the array.

unshift()

unshift(): Adds an item to the start of the array.

shift()

shift(): Removes an item from the start of the array.

sort()

sort(): Sorts the array by alphabetical order or numerical order.

length

length: Identifies the number of items inside the array.

Example:

const number = [5, 8, 6, 2, 1, 0, 22];


number.push(100);

console.log(number);


number.pop();

console.log(number);


number.shift();

console.log(number);


number.unshift(200);

console.log(number);


number.sort((a, b) => (a - b));

console.log(number);


console.log(number.length);

Console

[5, 8, 6, 2, 1, 0, 22, 100]

[5, 8, 6, 2, 1, 0, 22]

[8, 6, 2, 1, 0, 22]

[200, 8, 6, 2, 1, 0, 22]

[0, 1, 2, 6, 8, 22, 200]

The typeof Operator

You can use the typeof operator to find the type of the value.

typeof "" // returns "string" because empty quotes represent a string.

typeof (3 + 4) // returns "number"

typeof true // returns "boolean"

typeof undefined // returns "undefined"

Sprites with an Image in p5play

Use sprite.image (or sprite.img) to add an image to the sprite!

  • To add an image, you need to provide the URL path to an image file.
  • When developing a game, you can create an assets folder to store all images (in PNG or other formats).
  • Then, use the path as a URL. For example: 'assets/openedDoor.png'

let door;

function setup(){

  door = createSprite(50, 100, 50, 50);

  door.img = '/assets/openedDoor.png';

}

Try it! Replace the image of door into closedDoor.png

sprite.image.offset:

Use sprite.image.offset to adjust the image’s position relative to the center of the sprite.

You can make the image higher, lower, or more to the right or left.

It's especially useful when making a sprite collidable with other sprites.

function setup() {

  door = newSprite(50, 100, 50, 50);

  door.img = 'assets/openedDoor.png';

  door.img.offset.y = 10;

  door.img.offset.x = -10;

}

Try it! Change the door image offset to other values!


sprite.debug:

Set sprite.debug = true to see the sprite's physics body collider.

This is helpful, especially when you want to use sprite.image.offset because you can see the shape and center of the sprite.

function update(){

  clear();

  door.debug = true;

  // debug is in update because the collider needs to continue to show even when the sprite moves.

}

door.debug = false;

Try it! Change door.debug to true!
