JavaScript Operators

We can use operators to do math and create logic for the computer to function.

For example:

Assignment operator (=): let x = 100;

Multiplication operator (*): let gravity = 10;

Types of Operators:

In this lesson, you will learn about 5 types of operators: arithmetic operators, assignment operators, comparison operators, string operators, and logical operators. These are all operators that are commonly used in programming for beginners.

  • Arithmetic operators: Used for mathematical calculations (e.g. addition, subtraction).
  • Assignment operators: Used to assign values to variables (e.g. =, +=, -=).
  • Comparison operators: Used to compare two values (e.g. ==, ===, <, >).
  • String operators: Used to manipulate strings (e.g. + for concatenation).
  • Logical operators: Used for logical operations (e.g. &&, ||, !).

First, let's talk about arithmetic operators:

Arithmetic Operators:

The arithmetic operators are often used in math calculations.

Here are the common arithmetic operators:

  • = (Assignment)
  • + (Addition)
  • - (Subtraction)
  • * (Multiplication)
  • / (Division)
  • ^ (Exponentiation)

For example:

let x = 10;

let y = 5;

let result = x + y;

console.log(result);

Console

15

Remainder, Increment, and Decrement Operators

You may not know remainder, increment, and decrement. What are they?

Remainder:

The modulus operator (%) returns the division remainder.

Increment:

The increment operator (++) increases the variable's value by 1.

Decrement:

The decrement operator (--) decreases the variable's value by 1.

Examples:

a = 10;

b = 30;

console.log(a % b);

console.log(a++);

console.log(b--);

Console

10

11

29

Assignment Operators

Assignment operators assign value to variables.

Example:

let energy = 50;

energy += 30; // The addition assignment operator (+=) adds a value to variable (50+30)

console.log("Current Energy:", energy);

Console

Current Energy: 80
