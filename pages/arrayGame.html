    Array

    A giant ball is about to hit the poor alien!
    Drag and drop code blocks from the toolbox into the space below.
    Create a ball that speeds up when it hits the speed-up plate and knocks away the rock!
    Then, rescue the alien trapped by a trap by creating sprites in different locations.

    Instruction:

    1. Create variables in this order: ball, speedUpPlate, crate1, crate2, crate3, block1, block2, block3.

    2. Create an array to store: crate1, crate2, crate3, block1, block2, block3.

    3. Set the ball’s collider to "dynamic".

    4. Set the ball’s mass to 100.

    5. Set the ball’s direction to 180 and speed to 5.

    6. Use the array and its indices to:

        - Make each variable in the array a sprite in this order: crate1, crate2, crate3, block1, block2, block3.

        - Set each sprite’s collider to "dynamic".

        - Move each sprite to its position in this sequence:
            crate1 → (10, 10)
            crate2 → (20, 20)
            crate3 → (30, 30)
            block1 → (40, 40)
            block2 → (50, 50)
            block3 → (60, 60)
