    Array

    A giant ball is about to hit the poor alien!
    Drag and drop code blocks from the toolbox into the space below.
    Create a ball that speeds up when it hits the speed-up plate and knocks away the rock!
    Then, rescue the alien trapped by a trap by creating sprites in different locations.

    Instruction:

    1. Create a sprite called ball.

    3. Set the ball’s collider to "dynamic".

    4. Set the ball’s mass to 20.

    5. Set the ball’s direction to -20 and speed to 10.

    6. Create an array to store 6 new Sprite objects by assigning their locations in the following sequence:

        -(151, 321)
        -(375, 210)
        -(500, 275)
        -(280, 385)
        -(80, 500)
        -(580, 400)

    7. Set each sprite’s collider to "dynamic" using its index in the array (from index 0 to 5).

    8. Set each sprite’s image to "/assets/crate.png" in the same sequence as above.

    
let ball = new Sprite();
ball.collider = "dynamic";
ball.mass = 20;
ball.direction = -20;
ball.speed = 10;

let sprites = [
    new Sprite(151, 321),
    new Sprite(375, 210),
    new Sprite(500, 275),
    new Sprite(280, 385),
    new Sprite(80, 500),
    new Sprite(580, 400)
];

sprites[0].collider = "dynamic";
sprites[1].collider = "dynamic";
sprites[2].collider = "dynamic";
sprites[3].collider = "dynamic";
sprites[4].collider = "dynamic";
sprites[5].collider = "dynamic";

sprites[0].img = "/assets/crate.png";
sprites[1].img = "/assets/crate.png";
sprites[2].img = "/assets/crate.png";
sprites[3].img = "/assets/crate.png";
sprites[4].img = "/assets/crate.png";
sprites[5].img = "/assets/crate.png";
